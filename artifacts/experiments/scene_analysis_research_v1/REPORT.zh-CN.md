# ShotSense 场景感知自动修图：方案研究

2026-10-05。**个人研究阶段首选：MobileCLIP2-S0 提供场景证据，结合曝光、高光和噪点风险，控制现有自适应 LUT 与明暗处理；人脸位置在当前 Mac 上先复用 Apple Vision。**

这是一项基于当前代码、官方资料和本机离线原型的工程建议。识别及部署原型已验证，场景策略尚未接入页面，也没有验证新的修图效果。现有自动模式继续使用原来的处理流程。

## 为什么这样组合

目前 JPEG 的模型预测三个 LUT 的混合系数，保护层限制色彩变化，再依据暗部比例决定提亮。DNG 默认通过 RawTherapee 的固定亮度规则选择轻微曝光或保留原样。它们都缺少对人物、室内、夜景氛围的明确理解。

新模型适合回答“画面可能是什么”；调整策略需要另外回答“哪里需要改善、允许改多少”。一张照片可以同时是人物、室内、逆光。日落或夜景也可能曝光不足，不能识别到日落就禁止所有调整，或只因为画面暗就拉亮整张照片。识别结果应约束现有处理，而不是把每种类别固定绑定一个 LUT。

## 候选比较

| 候选 | 有用能力 | 本项目的判断 |
|---|---|---|
| MobileCLIP2-S0 | 用固定文字描述匹配图像，可以按修图需求设置人物、风景、室内、建筑等标签；图像编码器约11.4M参数 | 个人研究首选；本轮已测，场景证据有用，光照判断仍需限制 |
| Apple Vision 分类和人脸检测 | 系统自带多标签分类和人脸框，当前主程序无需新增 Python 包 | 人脸位置优先复用；广义分类不足以独自承担自动场景策略 |
| SigLIP2 Base | 图文语义匹配，官方提供零样本分类用法，模型卡标明 Apache2.0 | 后备比较对象；完整模型资源和接入成本较高，本轮未下载或实测 |
| Places365 | 365种环境/地点分类，适合室内外环境识别 | 标签体系主要描述地点，不能单独承担人物、夜景氛围及曝光策略；本轮未实测 |
| 从头训练场景或修图网络 | 可以定制目标 | 当前缺少独立代表性标签和修图偏好，暂不优先；先建立可检验基线 |

MobileCLIP2 的参数与用法来自 [作者仓库](https://github.com/apple-aiml-research/ml-mobileclip)，本文的选择是结合本地实验作出的工程判断，不是作者对照片修图的性能结论。其权重条款限定研究用途；用户已明确仅作个人研究，本轮据此开展实验。代码许可证和模型条款须分开记录。[权重条款](https://github.com/apple-aiml-research/ml-mobileclip/blob/main/LICENSE_MODELS)

Apple 将其分类器描述为在设备上运行的多标签网络；各类别分数不相加为1，也不应直接跨类别取最高值当作唯一类别。[Apple 官方说明](https://developer.apple.com/videos/play/wwdc2019/222/)

SigLIP2 的能力、许可证和官方用法见 [Google 模型卡](https://huggingface.co/google/siglip2-base-patch16-256)。Places365 的任务范围见 [作者仓库](https://github.com/CSAILVision/places365) 和 [官方类别表](https://github.com/CSAILVision/places365/blob/master/categories_places365.txt)。这些通用识别资料不证明在 ShotSense 中的实际编辑效果。

## 本轮实测说明

输入固定为此前17张照片的未调整 sRGB 缩略图：4张用户风景 JPEG、7张 DNG 的中性开发结果、6张公开暗光 JPEG。长边最多512像素，原照片和旧验证输出均保留。这批照片已被检查过，只有一个 DNG 人像，没有真实 JPEG 人像、宠物或充分的真实夜景覆盖，不能给出整体识别准确率。

MobileCLIP2 使用作者固定版本 `3136ea51c8ed56b9f9abfab04cb816735aaad6cb`，完整权重299,864,852字节，SHA256为 `bc3bc861baa680df2f9e3dc1aa0acbe5a21af21032df385026dda70c33505aa6`。用 `weights_only=True` 安全加载，再复用 OpenCLIP 的作者格式转换并严格检查全部权重；固定文本在推理前记录，没有按结果调提示词。CPU 单线程，缓存文本特征；同时比较官方中心裁剪与一个预先约定的全画面灰色补边视图。

- **主体/环境证据比较有用**：梯田、山湖、岩拱、阴天树群匹配风景；人像匹配人物；厨房和书柜偏室内；逆光废墟和建筑偏建筑；手套偏静物。这是有限样例观察，不是已通过的分类精度验收。沙发在两个视图间由静物变为室内，体现类别可重叠。
- **光照证据明显不够稳定**：17张中5张的最高光照匹配会随中心裁剪/全画面补边改变。包括岩拱、手套、剪影树、暗沙发、厨具；剪影树会由日落/日出变为白天欠曝。最高匹配和相邻匹配常很接近，不能当确定结论。没有独立夜景集，不能说已经能分清夜景和欠曝。
- **原生分类有局限**：Vision 在这台 Mac 上支持1,303个标签，分类revision2，人脸revision3。梯田的最高原始标签是 document/map，说明其通用分类也会失败。唯一人像检测到1个人脸，其他16张未检测到脸；这不足以验证人脸检测总体精度。原始类别分数和0.90精度筛选谓词都保留，父类别等未通过筛选的高分不能直接拿来控制编辑。
- **重复性**：两轮 native 标签分数及 MobileCLIP 文本匹配分数在这些固定输入上相同；重参数化前后图像特征最大差2.65e-7。没有训练或照片联网传输。

原图联系表已重新检查，主体观察与图像内容相符。极暗照片连人眼辨认都有困难；暗区中的低分识别只适合作为不确定证据。

## 运行成本与部署路径

| 测量 | 本机结果 | 范围 |
|---|---|---|
| Vision 分类+人脸+缩略图解码 | 第二轮p50约17.88ms、p95约19.33ms | 原生系统调度，非指定CPU测试；另3次单图新进程约0.20–0.21s且每次含2轮请求 |
| MobileCLIP2 Torch 缩略图准备+图像前向 | 第二轮p50约130.83ms、p95约144.78ms | 34个输入视图，CPU单线程；不含完整导入、模型和文本准备 |
| 仅图像编码器 FP32 ONNX | 45,555,991字节，约43.45MiB | 固定输入1×3×256×256，归一化512D输出 |
| ONNX模型前向 | p50约101.16ms、p95约104.48ms | CPU单线程，10次预热后50次计时，非完整照片处理 |
| 新进程无 Torch 的单图检查 | 约0.536s墙钟；导入后约0.237s | 岩拱全画面补边缩略图，含解码、会话准备、首轮前向；只测1次 |

ONNX 在全部17×2视图上的特征最大误差1.41e-6，分组最高匹配相同，重复输出位级相同；另外的新进程没有导入 Torch/OpenCLIP/Timm，文本匹配与完整Torch路径最大差1.05e-7。这验证了轻量部署的可行性，尚非生产接入验收。

因此运行时建议保存“图像 ONNX + 固定文本特征 + 标签/预处理版本”，复用现有 NumPy/Pillow/ONNX Runtime。约300MB的完整图文权重和本轮7个隔离研究包只用于准备/导出，不需要成为主程序的新依赖。识别处理缩略图，编辑和 PNG 导出仍保持原尺寸。模型约100ms不代表当前50MP照片能在100ms修完。

## 最小实现顺序

1. **先接入分析，验证可靠性。** 增加一个小的 `src/scene_analysis.py`：从已应用ICC/方向的 sRGB 基线获取缩略图，离线返回主体/环境匹配、独立的光照证据、不确定状态及必要的人脸位置。固定模型SHA、文本特征SHA、提示词和几何处理版本。不要显示“风景99%”一类未经校准的概率。原生人脸框只用于位置和区域统计，不能当精确皮肤分割。
2. **再控制现有 JPEG 自动策略。** 同时测原图/候选的明暗分布、高光与饱和风险、暗区噪点风险；人脸颜色优先保守，日落/夜景控制提亮幅度，普通风景按需要改善暗部。识别冲突时保持保守策略，不强行选一个类别。候选仅包括自然基线、较弱调色、有限暗部调整等少量已有操作；缩略图比较后只在原尺寸执行选中的方案。保持现有逐行内存控制、像素保护、缓存、PNG/JSON一致性与保存流程。不要用“直方图更均匀”或一个通用审美分数自动判最佳。
3. **独立完善暗光和 RAW。** 噪点估计只是风险指标，会受纹理和JPEG压缩影响；严重暗光需要另行验证受控降噪，不能仅放大提亮。之前固定双边滤波实验已失败，不能直接作为新默认。DNG可共用中性开发图的场景证据，但仍由原生RAW处理控制曝光、局部明暗/降噪；JPEG LUT不能直接作用于线性RAW，白平衡和高光恢复也须另行验证。暂不新增锐化。

不需要立即训练新的大模型或增加很多固定风格。后续如果简单规则有稳定偏差，再用用户对“原图/当前/候选”的选择数据训练小的参数或偏好选择器；只输出有界的编辑参数，保留所有现有保护和不确定回退。

## 验收要证明什么

建议新增60–100张此前未调过的新照片作为首轮覆盖目标，并按连拍/同场景分组，分开校准与留出验收。这个数量只是可执行的起点，不保证统计充分。应覆盖多肤色JPEG人像、多人/小脸、普通风景、室内混合光、日落剪影、真实夜景、白天欠曝、宠物、已经调好的照片及RAW；本轮17张只做回归。

同时记录标签错误、不确定比例、识别失败回退、用户改善偏好与坏改动比例，而不是只统计推理成功。特别核对肤色偏移、夜景被拉灰、天空剪裁、暗部噪点、原尺寸色阶/光晕、上传/切换/重试/缓存以及PNG/JSON是否一致。阈值在校准集上冻结后再看留出照片。遮挡脸、夜景和灰雾容易出现识别及审美歧义，应该作为可接受的不确定状态。
